## 3. BIỂU MẪU EXCEL DO CƠ QUAN THUẾ QUY ĐỊNH / TAX AUTHORITY'S PRESCRIBED EXCEL TEMPLATES

## 4. BIỂU MẪU XML DO CƠ QUAN THUẾ QUY ĐỊNH / TAX AUTHORITY'S PRESCRIBED XML TEMPLATES

**VN:** File XML tương thích HTKK, là **chuẩn bắt buộc** cho chức năng "Kết xuất XML". Bao gồm bản chính thức (chưa ký) và bản bổ sung (đã ký số, có khối `PLuc` + `CKyDTu`).

**EN:** HTKK-compatible XML files — the **mandatory standard** for the "Export XML" feature. Includes an official version (unsigned) and a supplementary version (digitally signed, with `PLuc` + `CKyDTu` blocks).

| File | Mô tả / Description |
|------|--------------------|
| `1201496252000-01_GTGT_TT80-Q22026-L00.xml` | Tờ khai chính thức, lần đầu (L00) / Official first-time declaration (L00) |
| `TGI-1201496252000-01_GTGT_TT80-Q22024-L01.xml` | Tờ khai bổ sung lần 1 (L01), đã ký số, đầy đủ phụ lục & giải trình / Supplement #1 (L01), digitally signed, full annexes & explanation |

**EN:**

- **Dev:** use group (1) as the primary implementation document; use groups (3)(4) as the export standard; refer to groups (2)(5) for detail/context.

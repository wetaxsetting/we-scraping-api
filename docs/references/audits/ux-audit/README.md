# audits/ux-audit/

UX parity / quality audits for `wecms-web`.

## Purpose

Audit each refactor screen against the Figma source of truth (WB365) and the live JEX behaviour. Capture token compliance (typography, spacing, colour), accessibility, copy / i18n correctness, and parity with the JEX feature behaviour.

## What goes here

- Per-screen audit (`<feature>-ux-audit-<yyyy-mm-dd>.md`)
- Tailwind token compliance check
- Desktop-first verification per memory `feedback_desktop_first_ui`
- Findings with severity and recommended action

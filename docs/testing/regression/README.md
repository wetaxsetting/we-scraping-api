# testing/regression/

Regression test suites for the refactor.

## Purpose

The standing set of tests that must pass before every merge to `main`. Drawn from prior bug fixes, parity audits, and pre-existing UAT scripts that proved load-bearing.

## What goes here

- Per-feature regression suite definition (which test ids belong to the regression set)
- Backfill log (which bug fix added which regression test)
- Suite execution policy (when to run, who owns it)

# testing/uat/

User Acceptance Test scripts and reports.

## Purpose

UAT scenarios run by the PO / business stakeholders against the refactor stack. Each scenario walks an end-to-end user journey and records pass / fail with evidence.

## What goes here

- Per-feature UAT scenarios (`<feature>-uat.md`)
- UAT cycle reports (`uat-cycle-<yyyy-mm-dd>.md`)
- Sign-off log (which feature passed UAT, when, by whom)

# Functional Specification — Error Envelope

**Part of:** Common → error-envelope
**Last verified:** 2026-06-23

Defines the envelope shape, wire-naming rule, status semantics, trace-id format, and i18n resolution
that govern every WeCMS REST endpoint.

## 1. Envelope shape

### Success — `{ status, data }`

```json
{
  "status": { "error": false, "code": "WBI0000", "message": "Success" },
  "data":   { ... }
}
```

- `CommonHead.success()` (`CommonHead.java:23-25`) = `{ error:false, code:"WBI0000", message:"Success" }`.
- `CommonHead.success(message)` (`CommonHead.java:27-29`) keeps `WBI0000` but lets the caller supply the message.
- `timestamp` / `path` / `trace_id` are `null` on success and dropped from the wire by
  `@JsonInclude(NON_NULL)` (`ApiResponse.java:32`).

### Error — adds `timestamp`, `path`, `trace_id`

```json
{
  "status":    { "error": true, "code": "WBE1009", "message": "ID or password does not match." },
  "timestamp": "2026-05-08T14:46:49Z",
  "path":      "/api/v1/auth/login",
  "trace_id":  "20260508144649PT06592776769567DEVL"
}
```

- `CommonHead.error(code, message)` (`CommonHead.java:31-33`) = `{ error:true, code, message }`.
- The three tracing fields are populated only by the four-arg `ApiResponse.error(code, message, path, traceId)`
  factory (`ApiResponse.java:71-73`); `timestamp = Instant.now()` (ISO-8601 UTC), `path = req.getRequestURI()`,
  `traceId = TraceId.current()`.

## 2. Wire naming — lowercase snake_case

- Wire property names are **lowercase snake_case**, enforced globally by `JacksonConfig` setting
  `PropertyNamingStrategies.SNAKE_CASE` on the auto-configured `ObjectMapper`. No per-DTO `@JsonNaming`.
- Java DTO fields stay **camelCase** (`expiresIn` → `expires_in`); the global strategy converts on
  serialize/deserialize.
- `CommonHead` fields (`error`, `code`, `message`) are already lowercase single words, so the strategy is
  a no-op for them (`CommonHead.java:8-12`). `ApiResponse.traceId` → wire `trace_id`.
- `@JsonProperty` is reserved for the rare case where the wire name diverges from the snake-cased Java
  field. The single canonical example is `LoginResponse.accessToken` → `@JsonProperty("access_token")`
  (OAuth-style). Adding any new UPPER/PascalCase `@JsonProperty` is forbidden except the Coocon/NXiSAS
  vendor gateway DTOs.

## 3. Status semantics

| `status.error` | Meaning | HTTP |
|---|---|---|
| `false` | Success or known business outcome that the frontend treats as data | `200` |
| `true` (`BusinessException`) | Documented business failure (e.g. `WBE1009`) | `200` — frontend reads `status.error`, not the HTTP code |
| `true` (client mistake) | Bad request / wrong method / unsupported media / not found | `4xx` |
| `true` (server fault) | DB error / timeout / unmapped runtime | `5xx` |

Rule: business outcomes → 200; client mistakes → 4xx; server faults → 5xx
(`GlobalExceptionHandler.java:41-44`). The frontend's primary success/failure signal is
**always `status.error`**, never the HTTP status alone.

## 4. Trace-id format

Generated by `TraceId.generate()` (`TraceId.java:33-39`):

```
yyyyMMddHHmmss  +  "PT"  +  <14 SecureRandom digits>  +  "DEVL"
└─ LocalDateTime.now()      └─ literal                   └─ literal
```

Example: `20260508144649PT06592776769567DEVL`.

- Mirrors the legacy JEX correlation-id shape so an id quoted from the error dialog greps verbatim
  against server logs + audit tables.
- Lives in MDC under `traceId` (`TraceId.MDC_KEY`) for the request duration; echoed in the `X-Trace-Id`
  header (`TraceIdFilter.HEADER_NAME`).
- `TraceId.current()` returns the MDC value, generating a fresh one only if absent (`TraceId.java:43-46`).

## 5. i18n resolution

- `MessageResolver` (`MessageResolver.java`) wraps Spring `MessageSource` (basename `messages`).
  `resolve(code, args…)` (`MessageResolver.java:20-23`) reads the locale from `LocaleContextHolder` and
  falls back to the **code itself** when the bundle has no entry.
- A second overload `resolve(code, Locale, args…)` (`MessageResolver.java:43-45`) resolves in an explicit
  locale, ignoring the request scope — used by the audit-log writer to fan one key across EN/KO/VI/KM.
- Locale is resolved at the controller from `Accept-Language` into the `LangCd` enum `{EN, KO, VI, KM}`
  (`LangCd.fromAcceptLanguage(...)`), then embedded in the JWT `langCd` claim so downstream code reads it
  from `TenantContext.currentLangCd()` instead of re-parsing the header.
- Message keys are WBE/WBI codes (e.g. `WBE1009=ID or password does not match.`). JEX ML code ids
  (`P00001`, …) are **never reused verbatim** — translate to `WBExxxx`/`WBIxxxx`.
- `RelativeTimeFormatter` (`RelativeTimeFormatter.java`) is the server-side "X ago" mirror of the
  frontend `lib/datetime.ts`, used where the backend itself renders a Last-Update string (Excel export);
  it localizes via `MessageResolver` against `relative_time.*` keys and parses legacy `yyyyMMdd[HHmmss]`
  as UTC.

## 6. Audit-column contract (BaseEntity)

Every entity mapped to a legacy JEX table extends `BaseEntity` and inherits four audit columns —
`REG_ID`, `REG_DTM`, `MOD_ID`, `MOD_DTM` (`BaseEntity.java:22-34`). `@PrePersist` sets both timestamps on
create; `@PreUpdate` refreshes `MOD_DTM` (`BaseEntity.java:36-46`). `REG_DTM`/`MOD_DTM` are Java
`OffsetDateTime` but persist as legacy `varchar(14)` `yyyyMMddHHmmss` UTC via `LegacyDtmConverter`
(`LegacyDtmConverter.java`). See [database-mapping.md](database-mapping.md).

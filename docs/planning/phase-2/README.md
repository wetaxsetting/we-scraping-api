# planning/phase-2/

Sprint plans and task lists for **Phase 2** of the refactor.

## Purpose

Phase 2 covers the accounting / WABOOKS module, reporting, e-invoice add-ons, and the remaining settings surface area. Sequenced after Phase 1's foundational delivery.

## What goes here

- Per-sprint task plans
- Per-feature plans tied to a Phase 2 deliverable
- Dependency notes pointing back at Phase 1 deliverables

## Naming convention

- kebab-case
- Sprint plans: `task-sprint-<n>-<codename>.md`
- Feature plans: `<feature>-plan.md`, slug matches the feature

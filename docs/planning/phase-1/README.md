# planning/phase-1/

Sprint plans and task lists for **Phase 1** of the refactor.

## Purpose

Phase 1 is the foundational sprint set: login, banking inquiry, transfer execution, approval-line, contacts, and the supporting common back-end. Per memory `project_team_roster`, the team commits 8 dev days + 2 test days per sprint cycle.

> **Most Phase-1 plans are complete and archived.** The shipped-feature task plans (approval-line, chart-of-accounts, contacts, transfer-history, sprint-0 login, sprint-1) now live read-only under [../../archive/planning/phase-1/](../../archive/planning/phase-1/). What remains here is the still-in-flight [account-inquiry-and-transaction-history-plan.md](account-inquiry-and-transaction-history-plan.md) (Account Inquiry shipped; Transaction-History frontend wiring is the residual work).

## What goes here

- Per-sprint task plans (`task-sprint-<n>-<codename>.md`)
- Per-feature plans tied to a Phase 1 deliverable
- Backlog / capacity worksheet for the phase

## Naming convention

- kebab-case
- Sprint plans: `task-sprint-<n>-<codename>.md`
